# Build 05 — Clinical Workflow

Controlled lifecycle for AI-assisted documentation.

## Note state machine
DRAFT → IN_REVIEW → APPROVED → FINAL

Alternative terminal states:
REJECTED, VOIDED.

Mr. NOVA/NovaClerk may create and revise drafts. A qualified human reviewer is responsible for approval/finalization according to tenant policy.

## Quality gates
- correct patient
- correct encounter
- required fields present
- provenance preserved
- unresolved contradictions surfaced
- reviewer identified
- finalization authorization valid
