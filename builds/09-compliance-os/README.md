# Build 09 — Evidence + Compliance Operating System

Core loop:
Requirement → Interpretation → Evidence → Evaluation → Gap → Corrective Action → Verification → Readiness.

A missing document is not automatically proof of non-compliance; the system distinguishes GAP from INSUFFICIENT_EVIDENCE.

Readiness is explainable and evidence-backed. Funding readiness is advisory and never represents government award, approval, licensure decision or guaranteed funding.
