# Build 10 — NOVA Command Center

The operator cockpit for NovaCarïs.

## Purpose
Bring the outputs of Builds 01–09 into one controlled command surface for authorized users.

The Command Center does not replace:
- Identity + Trust
- Agent Control
- Clinical Workflow
- Compliance evaluation
- EHR authorization
- Audit

It consumes those systems and presents their current state.

## Command domains
- Today / Operations
- Mr. NOVA agent activity
- Tasks and approvals
- Clinical documentation queue
- Compliance readiness
- Evidence gaps
- Corrective actions
- Funding readiness
- EHR integration health
- Alerts and exceptions
- Audit trail

## Core interaction
OBSERVE → INVESTIGATE → RECOMMEND → AUTHORIZE → EXECUTE → VERIFY.

## Human control
Consequential actions always route through the existing authorization and policy controls. The Command Center cannot approve an action merely because a user clicked a dashboard button.

## Build 10 objective
Give an executive, clinical, compliance or operations user one place to understand what requires attention, why it matters, what evidence supports it, what Mr. NOVA recommends, and what human authorization is required.
