# Build 10 MVP Scope

## MVP 1 — Command Dashboard
- readiness score
- critical gaps
- open corrective actions
- pending approvals
- agent status
- EHR health
- documentation queue
- alerts

## MVP 2 — Mr. NOVA Investigation
A user can select a card and ask Mr. NOVA:
- Why is this showing?
- What evidence supports it?
- What is missing?
- What should we do next?

## MVP 3 — Governed Actions
User can:
- assign a corrective action
- request evidence
- prepare a documentation draft
- prepare an EHR request
- approve an eligible action

All consequential execution remains outside the dashboard and goes through the existing control plane.

## MVP 4 — Executive Readiness
Organization-level view of:
Compliance + Evidence + Corrective Actions + Funding Readiness.

This creates the operating bridge from regulatory readiness to organizational execution.
