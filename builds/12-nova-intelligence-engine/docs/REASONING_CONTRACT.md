# NOVA Reasoning Contract

Every intelligence run must have:

1. authenticated requester
2. tenant scope
3. subject scope where applicable
4. purpose
5. permitted context
6. evidence retrieval
7. reasoning output
8. confidence
9. risk
10. authorization requirement
11. provenance
12. audit correlation

## Evidence hierarchy

Prefer:
1. current authoritative organizational records
2. verified regulatory/knowledge sources
3. verified internal evidence
4. historical context
5. model-generated inference

Inference must never be presented as authoritative evidence.

## Unknowns

If evidence is incomplete or contradictory, NOVA must surface the uncertainty rather than silently fill the gap.
