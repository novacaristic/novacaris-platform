# Recommendation Model

A recommendation contains:

- recommendation_id
- title
- problem statement
- observed facts
- evidence references
- inference
- confidence
- expected benefit
- risk
- dependencies
- proposed next action
- authorization requirement
- verification criteria

## Example

Problem:
Corrective action remains open.

Facts:
Evidence has not been verified.

Evidence:
Requirement and evidence records.

Recommendation:
Request updated evidence and assign an owner.

Authorization:
Required if the assignment creates an accountable organizational task.

Verification:
Re-run the requirement evaluation after evidence is received.

The recommendation is not execution.
