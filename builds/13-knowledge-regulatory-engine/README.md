# Build 13 — NOVA Knowledge & Regulatory Engine

The governed knowledge layer for regulations, policies, guidance, standards and organizational requirements.

## Core pipeline

SOURCE → INGEST → VERSION → PARSE → CLASSIFY → INTERPRET → MAP → EVIDENCE → EVALUATE → READINESS.

## Purpose

Build 13 makes regulatory and operational knowledge machine-usable while preserving source provenance and human review.

Supported knowledge types:
- regulation
- statute
- administrative rule
- licensing requirement
- Medicaid/provider requirement
- accreditation standard
- official guidance
- organizational policy
- contract requirement
- grant/funding requirement

## Critical boundary

NOVA may interpret and organize authoritative material, but an AI interpretation is not itself legal authority.

Every interpretation must retain:
- authoritative source
- source version
- jurisdiction
- effective dates
- source location
- interpretation status
- confidence
- reviewer where required

Superseded requirements remain historically addressable for auditability.
