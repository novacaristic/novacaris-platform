# Requirement Mapping

The mapping layer connects authoritative knowledge to Build 09 requirements.

Example:

Regulatory source
→ interpreted obligation
→ NovaCarïs requirement
→ evidence needed
→ compliance finding
→ corrective action
→ verification
→ readiness score.

A single source may map to multiple requirements.

A requirement may map to multiple sources.

Mappings are explainable and version-aware.
