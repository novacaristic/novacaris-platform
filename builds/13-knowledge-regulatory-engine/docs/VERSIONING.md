# Regulatory Versioning

Every knowledge source is versioned.

Required metadata:
- publication date
- effective date
- expiration/end date when applicable
- retrieval timestamp
- content hash
- canonical source
- superseded version

## Change detection

A new source version creates a change event.

Change events may be classified:
- administrative
- wording
- substantive
- effective-date
- applicability
- unknown

Unknown or substantive changes require review before they are used for consequential readiness decisions.

Historical versions remain queryable for audit reconstruction.
