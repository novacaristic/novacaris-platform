# Build 14 — NOVA Evidence Acquisition & Verification Engine

Build 14 connects Build 13 regulatory requirements to real organizational evidence.

## Core loop

REQUIREMENT → EVIDENCE REQUEST → ACQUISITION → VALIDATION → VERIFICATION → GAP/CONFIRMED → READINESS.

## Evidence types

- license/certificate
- policy/procedure
- training record
- personnel record
- inspection record
- audit record
- contract/payer document
- system configuration
- operational log
- meeting/approval record
- corrective-action proof

## Principles

Evidence must have provenance, owner, status, timestamps and applicability.

NOVA may request, classify and verify evidence according to configured rules. Human review remains available for ambiguous or consequential verification.

A missing artifact is not automatically proof of non-compliance.
