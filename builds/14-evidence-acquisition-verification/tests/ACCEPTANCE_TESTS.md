# Build 14 Acceptance Tests

- [ ] Evidence request is linked to a requirement when applicable.
- [ ] Evidence submission retains provenance.
- [ ] Content hash is recorded.
- [ ] Verification records verifier type and rationale.
- [ ] Authentic evidence can still be classified insufficient.
- [ ] Expired evidence is detectable.
- [ ] Superseded evidence remains historically traceable.
- [ ] Ambiguous evidence can route to human review.
- [ ] NOVA cannot fabricate evidence.
- [ ] NOVA cannot silently alter verified evidence.
- [ ] Verified evidence can trigger Build 09 re-evaluation.
- [ ] Every verification event is auditable.
