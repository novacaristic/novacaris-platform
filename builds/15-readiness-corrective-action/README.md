# Build 15 — NOVA Readiness & Corrective Action Engine

Build 15 converts regulatory requirements, verified evidence and compliance findings into an explainable organizational readiness program.

## Core loop

REQUIREMENT → EVIDENCE → FINDING → RISK → CORRECTIVE ACTION → OWNER → DUE DATE → VERIFICATION → REASSESSMENT.

## Readiness domains

- licensing readiness
- Medicaid/provider readiness
- accreditation readiness
- audit readiness
- operational readiness
- funding readiness
- corrective-action readiness

## Principles

Readiness is a decision-support score, not a legal determination or government approval.

Critical unresolved gaps can override a numerical score.

Every score must be explainable from requirements, evidence, findings and actions.

Corrective actions are not considered complete merely because a user marks them complete; verification criteria must be satisfied.
