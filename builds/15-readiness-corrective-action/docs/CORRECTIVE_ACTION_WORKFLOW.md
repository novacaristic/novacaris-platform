# Corrective Action Workflow

1. Identify gap.
2. Determine severity.
3. Define desired outcome.
4. Draft action plan.
5. Assign accountable owner.
6. Set due date.
7. Obtain authorization where required.
8. Execute through governed workflows.
9. Submit completion evidence.
10. Verify outcome.
11. Close or reopen action.
12. Recalculate readiness.

Completion without verification is not closure for actions requiring evidence.
