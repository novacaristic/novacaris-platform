# Readiness Explanation Contract

Every readiness assessment must answer:

1. What is the current score?
2. What status does the score represent?
3. Which requirements contribute most?
4. What evidence supports the assessment?
5. What critical gaps remain?
6. Which corrective actions are open?
7. What could change the score?
8. When was the assessment calculated?
9. Which scoring-model version was used?
10. What human overrides exist?

The explanation must be reproducible from stored assessment inputs.
