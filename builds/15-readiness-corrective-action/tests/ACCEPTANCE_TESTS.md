# Build 15 Acceptance Tests

- [ ] Readiness assessment is reproducible from stored inputs.
- [ ] Score uses the configured scoring-model version.
- [ ] Critical unresolved gaps override a passing numerical score.
- [ ] Expired critical evidence prevents READY.
- [ ] Missing evidence is distinguished from verified non-compliance.
- [ ] Every gap links to a requirement/finding when available.
- [ ] Corrective actions have owners and due dates.
- [ ] Completion evidence is retained.
- [ ] Required verification occurs before closure.
- [ ] Failed verification reopens the action.
- [ ] Assessment history is preserved.
- [ ] Human overrides are auditable.
- [ ] Readiness never represents legal approval or guaranteed funding.
