# Build 17 — NOVA Organizational Memory & Knowledge Graph

Build 17 creates the persistent relationship layer for NovaCarïs.

## Purpose

Connect organizational facts across time so Mr. NOVA can answer not only "what is true?" but "how is it connected, what changed, where did it come from, and what depends on it?"

## Graph domains

- organization
- people
- roles
- services
- locations
- requirements
- regulations
- evidence
- findings
- corrective actions
- readiness profiles
- funding opportunities
- applications
- agents
- tools
- decisions
- encounters and workflow objects

## Core graph

ENTITY → RELATIONSHIP → EVIDENCE → EVENT → DECISION → OUTCOME.

The graph is a relationship index, not a replacement for authoritative source tables.
