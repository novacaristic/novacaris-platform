# Graph Model

## Entity

A persistent object represented in the organizational graph.

Examples:
Organization, Person, Service, Requirement, Evidence, Finding, Action, Opportunity.

## Relationship

A typed connection between two entities.

Examples:
REQUIRES
SUPPORTED_BY
OWNED_BY
ASSIGNED_TO
APPLIES_TO
DEPENDS_ON
SUPERSEDES
RESULTED_IN
ELIGIBLE_FOR
ADDRESSES
VERIFIED_BY

## Assertion

A claim about an entity with provenance, confidence and validity dates.

The graph must distinguish an assertion from an authoritative source record.
