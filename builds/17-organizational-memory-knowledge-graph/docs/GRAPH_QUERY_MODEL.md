# Graph Query Model

Common query patterns:

## Dependency
What requirements depend on this regulation?

## Evidence
What evidence supports this requirement?

## Impact
What organizational processes are affected by this regulatory change?

## Ownership
Who owns the corrective actions associated with this finding?

## Readiness
Which open gaps are preventing this readiness profile from reaching READY?

## Funding
Which opportunities depend on evidence or capabilities the organization does not yet have?

## Decision trace
Why did NOVA make this recommendation?

Every query is tenant-scoped and subject to Build 01 authorization.
