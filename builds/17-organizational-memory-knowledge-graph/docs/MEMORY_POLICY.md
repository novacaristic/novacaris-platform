# Organizational Memory Policy

NOVA memory is scoped and purposeful.

## Allowed

- stable organizational facts
- verified workflow patterns
- approved policies
- historical decisions
- evidence relationships
- recurring operational dependencies
- user-approved preferences where appropriate

## Restricted

- sensitive patient information outside required scope
- unverified assumptions
- secrets or credentials
- unsupported legal conclusions
- speculative organizational facts

Patient-scoped information inherits the stricter access controls of Build 01 and must not leak into organization-wide memory.
