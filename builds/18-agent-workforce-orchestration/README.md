# Build 18 — NOVA Agent Workforce & Orchestration

Build 18 turns the NovaCarïs agent registry into a coordinated, role-based agent workforce.

## Agent model

One governance plane → many specialized agents → shared evidence/memory → controlled handoffs.

## Initial NOVA workforce

- Mr. NOVA — general orchestration and reasoning
- NOVA Compliance — regulatory and compliance analysis
- NOVA Evidence — evidence acquisition and verification
- NOVA Readiness — readiness and corrective-action analysis
- NOVA Funding — funding opportunity and application readiness
- NOVA Clinical — documentation workflow assistance
- NOVA Operations — operational queues and task coordination
- NOVA Integration — EHR/integration monitoring

Specialized agents are not separate authorities. They inherit Build 08 permissions, policies, scopes and approval requirements.

## Core workflow

REQUEST → ROUTER → SPECIALIST → EVIDENCE → SYNTHESIS → POLICY → HUMAN AUTHORIZATION → EXECUTION → VERIFICATION.
