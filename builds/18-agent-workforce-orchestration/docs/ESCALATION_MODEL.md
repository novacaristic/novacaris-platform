# Agent Escalation Model

Escalate when:

- evidence is insufficient
- evidence conflicts
- policy denies action
- required authorization is unavailable
- risk exceeds agent authority
- external side effect is requested
- clinical finalization is requested
- regulatory interpretation is materially uncertain
- agent confidence falls below configured threshold

Escalation target may be:
- another specialist
- supervisor
- compliance owner
- clinical reviewer
- executive/operator
- human authorization queue
