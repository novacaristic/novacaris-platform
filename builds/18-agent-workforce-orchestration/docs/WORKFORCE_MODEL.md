# Agent Workforce Model

## Mr. NOVA

The coordinating intelligence layer.

Responsibilities:
- understand objective
- route work
- synthesize specialist outputs
- surface conflicts
- prepare decisions

## Specialists

Each specialist has:
- registered agent identity
- version
- role
- allowed tools
- policy scope
- risk classification
- escalation rules
- owner
- health status

Specialists do not create permissions for themselves.
