# Workforce Policies

1. All agents are registered in Build 08.
2. All tools are registered in Build 08.
3. Agent-to-tool permissions are explicit.
4. Agent handoffs cannot elevate permissions.
5. Agent memory is tenant/scoped.
6. Specialist output requires provenance.
7. Consequential actions require existing authorization.
8. Agents cannot modify their own registry entries.
9. Agent failure must be visible.
10. A disabled agent cannot receive new work.
11. A workflow can be paused or terminated by authorized control.
12. Human override is recorded.
