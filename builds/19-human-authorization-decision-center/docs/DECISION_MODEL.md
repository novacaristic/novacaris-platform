# Decision Model

Every decision request contains:

- decision question
- source/recommendation
- evidence
- risk
- available options
- consequences
- policy requirements
- required approver level
- expiration rules
- verification criteria

The reviewer must be able to distinguish:
FACT
EVIDENCE
AI INFERENCE
RECOMMENDATION
POLICY REQUIREMENT
HUMAN DECISION.

These categories must not be collapsed into a single AI-generated statement.
