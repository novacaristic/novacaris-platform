# Build 19 Acceptance Tests

- [ ] Decision request is tenant-scoped.
- [ ] Reviewer identity comes from authenticated session.
- [ ] Evidence and recommendation are visible before decision.
- [ ] AI inference is distinguished from source evidence.
- [ ] Policy determines required approval level.
- [ ] Unauthorized users cannot approve.
- [ ] Approval cannot elevate permissions.
- [ ] High-risk actions can require multiple approvers.
- [ ] Authorization can expire.
- [ ] Revoked authorization cannot execute an action.
- [ ] Delegation is scoped and expires.
- [ ] Decision rationale is preserved.
- [ ] Conflicting evidence can block automatic execution.
- [ ] Decision events are auditable.
- [ ] Execution remains in the governed downstream subsystem.
