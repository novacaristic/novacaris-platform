# Cross-System Traceability

A single correlation ID should connect a consequential workflow across systems.

Example:

COMMAND REQUEST
→ NOVA INVESTIGATION
→ EVIDENCE RETRIEVAL
→ RECOMMENDATION
→ DECISION REQUEST
→ POLICY DECISION
→ AUTHORIZATION
→ EHR REQUEST
→ EHR RESULT
→ VERIFICATION.

The ledger stores references to the underlying authoritative records rather than duplicating their complete contents.
