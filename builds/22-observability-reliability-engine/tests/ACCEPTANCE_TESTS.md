# Build 22 Acceptance Tests

- [ ] Components can report HEALTHY, DEGRADED, UNAVAILABLE or UNKNOWN.
- [ ] Missing telemetry does not become false HEALTHY status.
- [ ] Metrics retain measurement timestamps.
- [ ] Health checks retain latency and details.
- [ ] Critical unavailability can create an incident.
- [ ] Critical incidents generate alerts.
- [ ] Alerts are severity-ranked and correlatable.
- [ ] SLOs retain measurement windows and error budgets.
- [ ] Agent reliability is measurable.
- [ ] EHR failures remain visible.
- [ ] Reliability data does not expose unnecessary sensitive payloads.
- [ ] Critical incidents can link to Trust Ledger events.
- [ ] Incident resolution retains remediation and verification.
