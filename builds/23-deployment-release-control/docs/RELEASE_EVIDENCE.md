# Release Evidence

Every production release should be able to answer:

- What version?
- Which source revision?
- Which artifacts?
- Which migrations?
- Which configuration version?
- Which feature flags?
- Who approved?
- Who/what deployed it?
- When?
- Which environment?
- Which verification checks passed?
- Was rollback required?
- What did Build 22 observe afterward?

Release evidence should correlate with Build 20 Trust Ledger and Build 22 reliability telemetry.
