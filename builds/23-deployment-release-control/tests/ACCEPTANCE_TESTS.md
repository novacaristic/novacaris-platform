# Build 23 Acceptance Tests

- [ ] Development, staging and production are distinct environments.
- [ ] Production promotion requires approval.
- [ ] Releases retain source revision.
- [ ] Deployment is idempotency-protected.
- [ ] Required verification gates can block promotion.
- [ ] Failed required gates trigger controlled rollback.
- [ ] Migrations are versioned and checksum-tracked.
- [ ] Migration failure blocks release completion.
- [ ] Configuration versions are traceable.
- [ ] Secrets are not stored in ordinary configuration records.
- [ ] Feature flags are environment-scoped and auditable.
- [ ] Release events record promotion and rollback.
- [ ] Production releases have verifiable evidence.
- [ ] Release evidence correlates with reliability and trust records.
