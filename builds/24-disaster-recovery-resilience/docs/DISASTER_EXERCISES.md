# Disaster Recovery Exercises

Exercises should test realistic scenarios such as:

- primary database failure
- region/service outage
- EHR dependency loss
- queue backlog
- corrupted deployment
- security containment
- credential/key service outage

Each exercise records:
- scenario
- expected recovery path
- actual recovery time
- data recovery point
- failures
- corrective actions
- retest requirement

Exercises produce evidence; they are not merely checklist activities.
