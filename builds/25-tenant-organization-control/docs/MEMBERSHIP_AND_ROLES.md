# Membership & Roles

Membership answers:

"Does this user belong to this organization?"

Role answers:

"What organizational permissions does this user have?"

Scope answers:

"Where may those permissions be exercised?"

Scope can include:
- location
- department
- program

Membership revocation must take effect before further protected operations are authorized.

Build 25 does not replace Build 08 policy enforcement. It supplies organizational identity and scope to that policy system.
