# Service Entitlements

A tenant may have specific NovaCarïs services enabled or disabled.

Examples:
- Compliance
- Evidence
- Readiness
- Funding
- Command Center
- NovaClerk
- EHR integrations
- Academy
- Consultancy workflows

Service enablement is an organizational configuration boundary.

Commercial entitlement rules belong to Build 26; Build 25 records whether a service is operationally enabled.
