# Build 25 Acceptance Tests

- [ ] Organizations have an explicit lifecycle.
- [ ] Tenant context is required for protected operations.
- [ ] Deactivated tenants cannot execute ordinary workflows.
- [ ] Tenant membership is distinct from role.
- [ ] Role is distinct from location/department/program scope.
- [ ] Membership revocation can block future protected operations.
- [ ] Services can be enabled per tenant.
- [ ] Tenant policies cannot weaken platform controls.
- [ ] Agents inherit tenant context.
- [ ] Tenant agent configuration cannot elevate Build 08 permissions.
- [ ] Integrations are tenant-owned.
- [ ] Tenant events are retained.
- [ ] Cross-tenant access requires explicit authorization.
- [ ] Historical evidence is preserved through suspension/deactivation.
