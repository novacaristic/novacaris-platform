# Entitlement Model

An entitlement answers:

"May this tenant use this NovaCarïs feature under its current commercial configuration?"

Examples:
- nova.command_center
- nova.compliance
- nova.readiness
- nova.funding
- novaclerk.voice
- ehr.integration
- academy.training
- consultancy.workflow

Entitlement is only one gate.

A feature may still require:
- authentication
- tenant scope
- role permission
- Build 08 policy
- Build 21 security decision
- human authorization

Commercial entitlement never creates security authority.
