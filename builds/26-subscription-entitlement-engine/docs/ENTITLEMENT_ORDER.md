# Entitlement Decision Order

Recommended authorization chain:

1. Authenticate user/session
2. Resolve tenant
3. Confirm membership/scope
4. Check commercial entitlement
5. Apply Build 08 policy
6. Apply Build 21 security/privacy controls
7. Require Build 19 human authorization when applicable
8. Execute
9. Record usage where applicable
10. Record trust/reliability events

Commercial entitlement is therefore necessary in some workflows but never sufficient for protected action.
