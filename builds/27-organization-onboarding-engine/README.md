# Build 27 — NOVA Organization Onboarding Engine

Build 27 converts a new NovaCarïs customer from an account into an operationally configured organization.

## Core loop

DISCOVER → PROVISION → CONFIGURE → INVITE → CONNECT → COLLECT → ASSESS → VERIFY → ACTIVATE → HANDOFF.

## Onboarding stages

1. Organization profile
2. Plan/subscription
3. Locations/programs
4. Users/roles
5. Services/modules
6. Policies
7. Integrations
8. Evidence
9. Readiness
10. Go-live verification

## Design principle

Onboarding is not a form wizard.

It is a controlled operational setup process that establishes the context required for NovaCarïs to work safely for a specific organization.

Mr. NOVA can guide, explain, recommend, prepare and detect missing information.

Human administrators remain responsible for organizational facts, permissions, certifications, attestations and final activation decisions.

## Relationship to previous builds

Build 25 establishes tenant/organization control.
Build 26 establishes commercial entitlement.
Build 27 turns both into a repeatable customer activation workflow.
