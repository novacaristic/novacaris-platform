# Onboarding Model

Onboarding is an explicit workflow with state, stages, requirements, tasks and evidence.

Core lifecycle:

STARTED → IN_PROGRESS → READY_FOR_ACTIVATION → ACTIVE

Blocked path:

IN_PROGRESS → BLOCKED → IN_PROGRESS

Cancellation:

IN_PROGRESS → CANCELED

Activation is a controlled decision, not an automatic consequence of completing a checklist.
