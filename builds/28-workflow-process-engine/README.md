# Build 28 — NOVA Workflow & Process Engine

Build 28 turns NovaCarïs capabilities into executable, governed organizational workflows.

## Core loop

DEFINE → TRIGGER → PLAN → EXECUTE → WAIT → ESCALATE → RESUME → VERIFY → COMPLETE.

## Purpose

A workflow is a controlled sequence of work, not merely a checklist.

Build 28 supports:
- workflow definitions
- versioning
- triggers
- stages
- tasks
- dependencies
- conditions
- timers
- approvals
- human tasks
- agent tasks
- evidence requirements
- escalations
- retries
- pause/resume
- cancellation
- completion verification

## Governance

Workflow execution remains subordinate to:
- Build 08 Agent Control Plane
- Build 19 Human Authorization
- Build 21 Security & Privacy
- Build 22 Reliability
- Build 23 Release Control
- Build 25 Tenant Control
- Build 26 Entitlements

A workflow cannot grant permissions merely because a step exists in its definition.

## Design principle

NOVA should automate the movement of work while preserving human authority over consequential decisions.
