# AI Draft Policy

Mr. NOVA may:

- draft content
- populate authorized fields
- summarize source evidence
- identify missing information
- suggest edits
- prepare alternate versions

Mr. NOVA may not:

- fabricate facts
- silently change source evidence
- represent a draft as final
- self-approve
- self-sign
- create a false attestation
- bypass required human review

Generated content should retain provenance to the inputs used where feasible.
