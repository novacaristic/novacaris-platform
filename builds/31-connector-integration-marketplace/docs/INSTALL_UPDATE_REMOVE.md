# Install, Update & Remove

Installation:
1. select published connector/version
2. verify tenant entitlement
3. review capabilities/scopes
4. configure secret references
5. obtain required approvals
6. run connection test
7. activate
8. record evidence

Updates:
- validate compatibility
- stage first
- preserve previous version reference
- support rollback when safe

Removal:
- stop new invocations
- revoke credentials/scopes
- resolve queued work
- retain audit and reconciliation history
