# Build 32 — NovaCarïs Academy & Training Management Engine

Build 32 provides course delivery, learner management, assessments and verifiable training records for the NovaCarïs ecosystem.

## Core loop

COURSE → ENROLL → LEARN → ASSESS → REVIEW → COMPLETE → ISSUE RECORD → VERIFY → CONNECT TO READINESS.

## Scope

- courses and versions
- learning paths
- modules and lessons
- learner enrollment
- instructor assignments
- assessments and attempts
- completion criteria
- certificates/achievement records
- continuing education tracking
- organization-specific training
- evidence export/reference
- training analytics

## Commercial model

Academy access can be sold as a plan feature or add-on through Build 26.

## Important distinction

Course completion is not automatically equivalent to professional licensure, regulatory compliance, continuing-education approval or demonstrated workplace competency.

Only authorized, verified training records should be used as evidence in compliance/readiness workflows.
