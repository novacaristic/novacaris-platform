# Service Catalog

Service offerings should be versioned and clearly scoped.

Examples:
- operational readiness assessment
- compliance evidence organization
- policy/procedure development support
- corrective-action planning
- funding-readiness support
- technology implementation
- workflow optimization
- Academy training

Each offering should state:
- intended outcome
- included deliverables
- exclusions
- assumptions
- client responsibilities
- review requirements
- pricing model
- expected timeline
