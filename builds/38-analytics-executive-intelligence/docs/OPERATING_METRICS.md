# Operating Metrics

Suggested initial measures:
- subscription count by status
- monthly recurring revenue under a documented definition
- cash collected in period
- overdue invoice balance
- lead-to-opportunity and proposal conversion
- renewal rate and churn
- ticket backlog and response time
- onboarding milestone completion
- Academy course completion
- consultancy deliverable acceptance
- connector failure rate
- reliability SLO attainment
- readiness status by organization

Start with a small metric set that has reliable source data. Expand only when definitions, access controls and data quality are established.
