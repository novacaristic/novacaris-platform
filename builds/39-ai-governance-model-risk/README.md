# Build 39 — NOVA AI Governance & Model Risk Management

Build 39 governs AI models, model versions, prompts, evaluations, deployments, monitoring and retirement across the NovaCarïs ecosystem.

## Core loop

REGISTER → CLASSIFY RISK → DEFINE CONTROLS → EVALUATE → REVIEW → APPROVE → DEPLOY → MONITOR → REASSESS → ROLLBACK/RETIRE.

## Scope

- model/provider registry
- model versions and capability declarations
- AI use-case inventory and risk tier
- evaluation plans, runs and evidence
- prompt/system-instruction version references
- release and deployment approvals
- performance, safety and drift observations
- model-related incidents
- corrective actions
- rollback and retirement records
- human oversight requirements
- governance audit trail

## Boundaries

This build complements Build 08 agent/tool authorization, Build 21 security/privacy controls, Build 20 trust ledger and Build 13 regulatory knowledge governance. It does not replace them.

A model's evaluation result is scoped to a particular version, configuration, use case and test set. Passing an evaluation is not proof of universal safety, regulatory compliance or clinical validity. High-impact use cases require appropriate expert review and meaningful human oversight.
