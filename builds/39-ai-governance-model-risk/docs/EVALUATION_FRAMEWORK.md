# Evaluation Framework

Evaluation plans should define:
- use case and model/configuration under test
- representative test set and version
- acceptance thresholds
- safety and refusal tests
- factuality and citation/provenance checks
- privacy and security tests
- robustness and edge cases
- subgroup performance where appropriate and lawful
- evaluator role
- failure severity
- remediation and retest requirements

A passing result applies only to the evaluated scope and configuration. Preserve failures; do not report only aggregate pass rates.
