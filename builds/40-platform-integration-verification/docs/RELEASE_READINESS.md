# Release Readiness

Release decisions:
- BLOCKED
- READY_WITH_CONDITIONS
- READY

A release decision must reference:
- exact source revision
- target environment
- verification run
- passed and failed checks
- unresolved findings
- exceptions and rationale
- accountable approver

No automated score can override a mandatory security, privacy, migration or critical-risk blocker. A release-ready record is not proof that a release was deployed.
