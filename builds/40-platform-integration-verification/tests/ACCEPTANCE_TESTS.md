# Build 40 Acceptance Tests

- [ ] Build registry records repository path and status.
- [ ] Dependencies identify provider/consumer and contract.
- [ ] Contract versions are pinned and compatibility is checked.
- [ ] Migration records include checksum and dependencies.
- [ ] Verification runs identify source revision and environment.
- [ ] Each result retains evidence and execution status.
- [ ] Missing required evidence blocks release readiness.
- [ ] Required failed/blocked/skipped checks block release readiness.
- [ ] Unresolved critical findings block release readiness.
- [ ] Optional failed checks yield conditional readiness.
- [ ] Tenant isolation and security scenarios are represented.
- [ ] End-to-end scenarios include failure paths and cleanup.
- [ ] Release decision includes an accountable human approver.
- [ ] Reports distinguish artifacts committed from tests executed.
