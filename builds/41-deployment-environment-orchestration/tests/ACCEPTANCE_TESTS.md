# Build 41 Acceptance Tests

- [ ] Environments have distinct configuration and secret references.
- [ ] Release manifests pin source revision and artifact digest.
- [ ] Missing source revision or artifact digest blocks deployment.
- [ ] Required checks must pass and include evidence.
- [ ] Staging/production migrations require an approved migration plan.
- [ ] Production requires accountable human approval.
- [ ] Missing rollback plan blocks deployment.
- [ ] Invalid secret/configuration references block deployment.
- [ ] Post-deployment checks are required for verified status.
- [ ] Unhealthy or evidence-free postchecks do not report success.
- [ ] Recovery records preserve target release and verification evidence.
- [ ] No live deployment is claimed by creating these artifacts alone.
