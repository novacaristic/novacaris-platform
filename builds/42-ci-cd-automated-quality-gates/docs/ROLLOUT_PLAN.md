# Rollout Plan

1. Review workflow YAML and permissions.
2. Confirm repository root package manager, scripts and lockfiles.
3. Run validation on a branch or manual workflow dispatch.
4. Fix workflow errors and missing test configuration.
5. Enable dependency and secret scanning settings.
6. Configure branch protection and protected environments.
7. Require passing checks on pull requests.
8. Verify staging deployment and smoke tests.
9. Keep production deployment manual until recovery is tested.
10. Reassess workflow changes periodically.
