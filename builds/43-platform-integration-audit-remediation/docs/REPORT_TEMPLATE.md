# Platform Audit Report Template

## Scope
Source revision, build range, environments and excluded components.

## Executive Summary
Verified strengths, limitations, blockers and recommended decision.

## Build Inventory
For each build: specified, committed, reviewed, tested, integrated, staging and production evidence.

## Dependency & Contract Findings
Missing or incompatible providers and interfaces.

## Database & Migration Findings
Schema conflicts, ordering, compatibility and recovery.

## Security & Privacy Findings
Evidence-backed issues, severity, impact and containment.

## Test Results
Exact commands, environment, revision and result evidence.

## Remediation Backlog
Finding, severity, owner, due date, fix, retest and closure evidence.

## Release Decision
BLOCKED / READY_WITH_CONDITIONS / READY, accountable approver and rationale.
