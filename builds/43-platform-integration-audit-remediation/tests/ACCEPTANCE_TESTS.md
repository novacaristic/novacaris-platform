# Build 43 Acceptance Tests

- [ ] Every build has a stable key and repository path.
- [ ] Status vocabulary distinguishes committed from tested and deployed.
- [ ] Tested-or-higher status requires evidence, revision, environment and passed result.
- [ ] Staging verification requires staging environment evidence.
- [ ] Production verification requires production environment evidence.
- [ ] Dependencies reference explicit contracts and verification status.
- [ ] Findings have severity, impact, status and remediation references.
- [ ] Open critical findings block release readiness.
- [ ] Missing evidence is reported as unverified, not as passed.
- [ ] Audit reports identify scope, revision, limitations and approver.
- [ ] Remediation closure requires retest evidence.
