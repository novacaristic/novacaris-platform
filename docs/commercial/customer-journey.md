# NovaCarïs Customer Journey

## Entry

A behavioral-health organization enters through:
- NOVA Snapshot
- NOVA Readiness Check
- Academy course
- Consulting discovery
- NovaCarïs software inquiry

## Core journey

`Lead → Intake → Readiness → Action Plan → Implementation → Verification → Advisory`

### Intake
Establish organization, sites, services, objectives and evidence references.

### Readiness
Mr. NOVA coordinates regulatory, evidence, MPRIME, funding, operations and AI-governance analysis.

### Action Plan
Findings become prioritized actions with human-review requirements.

### Implementation
Consulting, Academy and software are recommended according to the actual gaps.

### Verification
Evidence is collected and readiness is reassessed.

### Advisory
Recurring intelligence keeps the organization aware of regulatory, funding, technology and operational changes.

## Commercial cross-sell rule

Recommendations should follow demonstrated customer needs.

**No artificial product bundling.**

A customer may use:
- Academy only
- Consulting only
- Software only
- Academy + Consulting
- Consulting + Software
- Academy + Software
- full NovaCarïs transformation

## Strategic goal

Make the first assessment useful even when the customer purchases nothing else.

Trust is the acquisition strategy.
